# 🇳🇵 Sajilo Nepal

### A Civic Infrastructure Reporting & Resolution Platform for Nepal

**Sajilo Nepal** is a civic-tech platform that connects **citizens, municipal authorities, and field responders** through a centralized system for reporting, tracking, and resolving local infrastructure and public-service issues.

Citizens can report issues such as **road damage, waste, water leakage, traffic problems, electrical hazards, street-light failures, and other civic concerns**, while authorities can review, prioritize, assign, and monitor their resolution.
# https://sajilonepal.vercel.app

## ✨ Key Features

* 📝 Report civic issues with descriptions, locations, photos, and severity
* 🗺️ Interactive map for viewing reported issues
* 📍 Location-based issue reporting
* 📊 Citizen and municipal dashboards
* 🔎 Issue tracking with status updates
* 🏛️ Municipal administration and responder management
* 🚨 Severity and priority classification
* 📈 Resolution progress and activity history
* 📤 CSV data export
* 📱 Responsive interface for desktop and mobile

The platform follows a structured workflow from **report submission → municipal review → assignment → field response → resolution verification**.

## 🚀 Getting Started

```bash
git clone https://github.com/sandipta7/SajiloNepal.git
cd SajiloNepal
npm install
npm run dev
```

For production:

```bash
npm run build
npm run preview
```

> ⚠️ Never commit API keys, Firebase credentials, or other sensitive information to GitHub. Use environment variables and appropriate security rules.

## 🌏 Vision

> **Making civic participation simple, transparent, and connected.**

Sajilo Nepal aims to demonstrate how technology can improve communication between **citizens, communities, and local authorities** while making civic issue reporting more accessible and transparent.
